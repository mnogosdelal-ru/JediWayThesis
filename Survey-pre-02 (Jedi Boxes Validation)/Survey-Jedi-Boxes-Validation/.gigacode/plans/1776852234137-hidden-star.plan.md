## Цель
Исправить ошибки и улучшить качество кода в `generate_report.py` для подготовки к научной публикации.

## Задачи
1. Исправить расчёт дисперсии в тесте Джонкхира-Терпстры.
2. Исправить расчёт R² в квадратичной регрессии.
3. Добавить расчёт VIF для проверки мультиколлинеарности в множественной регрессии.
4. Добавить размер выборки (n) во все статистические тесты.
5. Добавить оценку мощности тестов, особенно при n < 50.

## Источники и инструменты
- `generate_report.py` — основной файл для исправления.
- `scipy.stats` — для статистических тестов.
- `statsmodels.stats.outliers_influence.variance_inflation_factor` — для расчёта VIF.
- `pingouin` — для оценки мощности (если установлен), иначе использовать `scipy`.
